# WebRTCManager FPS 与配置管理流程图

## 核心公式

```
缩放比例 = 采集FPS / 最大推送FPS
实际WebRTC推送FPS = min(最大推送FPS, 后端目标FPS / 缩放比例)
```

## 关键变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `currentCaptureFPS` | Int | 当前采集FPS（后置240/前置120） |
| `targetOutputFPS` | Int | 后端下发的目标FPS |
| `frameThrottler.targetSendFps` | Int | 本地节流器目标FPS |
| `maxPushFps` | Int | 当前档位的最高推送FPS上限 |
| `currentResolutionScale` | Double | 分辨率缩放比例 |

## 档位配置表

### LadderPreset 结构
```swift
struct LadderPreset {
    let width: Int          // 输出宽度
    let height: Int         // 输出高度
    let fps: Int            // 采集FPS（后置240/前置120）
    let maxKbps: Int        // 最大码率
    let maxPushFps: Int     // 🔥 最高推送FPS限制
}
```

### 后置摄像头（采集240fps）
| 档位 | 分辨率 | scale | maxPushFps | 缩放比例 |
|------|--------|-------|------------|---------|
| 4K | 1920×1080 | 1.0 | 60fps | 240/60=4 |
| 超清 | 1280×720 | 1.5 | 60fps | 240/60=4 |
| 高清 | 960×540 | 2.0 | 80fps | 240/80=3 |
| 标清 | 480×270 | 4.0 | 120fps | 240/120=2 |

### 前置摄像头（采集120fps）
| 档位 | 分辨率 | scale | maxPushFps | 缩放比例 |
|------|--------|-------|------------|---------|
| 4K | 1920×1080 | 1.0 | 60fps | 120/60=2 |
| 超清 | 1280×720 | 1.5 | 60fps | 120/60=2 |
| 高清 | 960×540 | 2.0 | 80fps | 120/80=1.5 |
| 标清 | 480×270 | 4.0 | 120fps | 120/120=1 |

                                  │

│ 3. calculateLadderForDevice(camera)                              │

┌─────────────────────────────────────────────────────────────────┐
│ 🔥 4. 设置采集FPS（关键！用于缩放计算）                            │

                                  │
                                  ▼
