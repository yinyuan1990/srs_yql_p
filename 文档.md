# iOS 前端试用/激活状态对接文档

## 概述

前端需要在两个地方判断试用/激活状态：
1. **登录时**：根据登录接口返回的 `trialInfo` 判断是否能进入主页
2. **推流时**：根据 WebSocket 返回的 `TryDisconnect` 消息判断是否需要强制退出

## 🔐 登录接口

### 响应格式
```json
{
    "success": true,
    "token": "JWT令牌",
    "username": "用户名",
    "userType": "VIP_VIEW",
    "message": "登录成功",
    
    // ========== 试用/激活信息 ==========
    "trialInfo": {
        "trialRequired": true/false,      // 是否需要试用限制
        "activated": true/false,          // 是否已激活
        "activationLevel": 1/2/null,      // 激活等级
        "activationLevelName": "白银"/"黄金"/null,
        "activationExpireAt": "2026-12-16T10:00:00",  // 激活到期时间
        "qualityAccess": ["标清", "高清"],
        
        // 未激活时的试用状态
        "trialEnded": true/false,         // 【重要】当天试用是否已全部结束
        "currentStage": 1-6,              // 当前试用阶段
        "totalStages": 6,
        "stageSeconds": 1800/300,
        "remainingSeconds": 1500,
        "usedSeconds": 300,
        "message": "提示信息"
    }
}
```

### 登录后判断逻辑

```
登录成功
    │
    ▼
trialInfo.trialRequired == true ?
    │
┌───┴───┐
No     Yes
│       │
▼       ▼
直接    trialInfo.trialEnded == true ?
进入         │
主页    ┌────┴────┐
       No       Yes
        │        │
        ▼        ▼
      进入    【弹框提示】

```

### 登录处理代码（Swift）

```swift
func handleLoginResponse(_ response: [String: Any]) {
    guard let success = response["success"] as? Bool, success,
          let trialInfo = response["trialInfo"] as? [String: Any] else {
        // 登录失败
        showError("登录失败")
        return
    }
    
    let trialRequired = trialInfo["trialRequired"] as? Bool ?? false
    
    // 不需要试用限制（已激活用户或非设备端）
    if !trialRequired {
        // 直接进入主页
        navigateToHome()
        return
    }
    
    // 需要试用限制，检查当天是否已用完
    let trialEnded = trialInfo["trialEnded"] as? Bool ?? false
    
    if trialEnded {
        // ⚠️ 当天试用已用完，弹框后强制退出
        showAlert(
            title: "试用已结束",
            message: "今日试用已用完，请明天再试或激活会员",
            actions: [
                AlertAction(title: "确定") {
                    // 强制退出应用
                    exit(0)
                }
            ]
        )
    } else {
        // 还有试用时间，可以进入主页
        let currentStage = trialInfo["currentStage"] as? Int ?? 1
        let remainingSeconds = trialInfo["remainingSeconds"] as? Int ?? 0
        let minutes = remainingSeconds / 60
        
        // 可选：提示用户剩余试用时间
        showToast("第\(currentStage)次试用，剩余\(minutes)分钟")
        
        // 进入主页
        navigateToHome()
    }
}
```

## 📡 WebSocket 通知消息结构

### 订阅频道
```
/topic/device/{deviceId}/config
```

### 消息格式

```json
{
    "type": "TryDisconnect",
    "deviceId": "设备ID",
    "username": "用户名",
    "state": { /* 设备状态对象 */ },
    "timestamp": "2025-12-16T10:30:00",
    
    // ========== 核心判断字段 ==========
    "shouldDisconnect": true/false,     // 【重要】是否需要断开连接
    "trialRequired": true/false,        // 是否需要试用限制（仅VIP_VIEW用户为true）
    
    // ========== 激活状态 ==========
    "activated": true/false,            // 是否已激活
    "activationLevel": 1/2/null,        // 激活等级 (1=白银, 2=黄金)
    "activationLevelName": "白银"/"黄金"/null,  // 等级名称
    "qualityAccess": ["标清", "高清"],  // 可用画质列表
    
    // ========== 试用状态（未激活时有效）==========
    "trialEnded": true/false,           // 当天试用是否已全部结束
    "currentStage": 1-6,                // 当前试用阶段（1-6）
    "totalStages": 6,                   // 总阶段数
    "stageSeconds": 1800/300,           // 当前阶段总秒数
    "remainingSeconds": 1500,           // 当前阶段剩余秒数
    "usedSeconds": 300,                 // 当前阶段已用秒数
    "stageJustEnded": 1/2/3.../null,    // 刚结束的阶段号（阶段结束时有值）
    "message": "提示信息"               // 提示文本
}
```

## 🚨 何时需要退出应用

### 判断逻辑流程图

```
收到 TryDisconnect 消息
         │
         ▼
   trialRequired == true ?
         │
    ┌────┴────┐
   No        Yes
    │         │
    ▼         ▼
  不需要    shouldDisconnect == true ?
  限制           │
              ┌──┴──┐
             No    Yes
              │     │
              ▼     ▼
           正常   【强制退出】
           使用
```

### 前端退出条件（伪代码）

```swift
// iOS Swift 示例
func handleTryDisconnect(notification: [String: Any]) {
    let trialRequired = notification["trialRequired"] as? Bool ?? false
    let shouldDisconnect = notification["shouldDisconnect"] as? Bool ?? false
    
    // 核心判断：是否需要强制退出
    if trialRequired && shouldDisconnect {
        // ⚠️ 强制退出！立即断开连接
        disconnect()
        
        let message = notification["message"] as? String ?? "试用时间已到"
        let trialEnded = notification["trialEnded"] as? Bool ?? false
        
        if trialEnded {
            // 今日试用全部结束
            showAlert(
                title: "试用结束",
                message: "今日试用次数已用完，请明天再试或激活会员",
                actions: ["激活会员", "确定"]
            )
        } else {
            // 当前阶段结束（也是强制退出）
            showAlert(
                title: "本次试用结束",
                message: message,
                actions: ["激活会员", "确定"]
            )
        }
    }
}
```

## 退出场景详解

### 场景1：当前阶段时间用完（强制退出）

| 字段 | 值 |
|------|-----|
| `shouldDisconnect` | `true` |
| `trialEnded` | `false` |
| `stageJustEnded` | `1` / `2` / `3` / `4` / `5` |
| `currentStage` | 下一阶段号 |
| `remainingSeconds` | 下一阶段的总秒数 |
| `message` | "第X次试用结束，还剩Y次机会" |

**前端处理**：
- **强制退出**：立即断开推流/拉流
- 弹窗提示用户当前阶段结束
- 用户想继续试用需重新打开应用（自动进入下一阶段）

---

### 场景2：当天所有试用次数用完（强制退出）

| 字段 | 值 |
|------|-----|
| `shouldDisconnect` | `true` |
| `trialEnded` | `true` |
| `stageJustEnded` | `6` |
| `currentStage` | `6` |
| `remainingSeconds` | `0` |
| `message` | "今日试用次数已用完" |

**前端处理**：
- **强制退出**：立即断开推流/拉流
- 弹窗提示用户今日试用已结束
- 引导用户激活会员
- 当天无法再使用（需等到第二天0点重置）

---

### 场景3：正常使用中（不需要退出）

| 字段 | 值 |
|------|-----|
| `shouldDisconnect` | `false` |
| `trialEnded` | `false` |
| `currentStage` | 当前阶段 |
| `remainingSeconds` | 剩余秒数（递减） |

**前端处理**：
- 可选择在界面显示剩余时间
- 正常处理设备状态更新

---

### 场景4：已激活用户（无试用限制）

| 字段 | 值 |
|------|-----|
| `trialRequired` | `false` |
| `shouldDisconnect` | `false` |
| `activated` | `true` |
| `activationLevel` | `1` 或 `2` |
| `qualityAccess` | `["标清", "高清"]` 或 `["标清", "高清", "超清", "4K"]` |

**前端处理**：
- 无需试用限制
- 可根据 `qualityAccess` 显示可用画质选项

---

### 场景5：非设备端用户（无试用限制）

| 字段 | 值 |
|------|-----|
| `trialRequired` | `false` |
| `shouldDisconnect` | `false` |

**前端处理**：
- 无需试用限制
- 正常使用

## 试用阶段说明

| 阶段 | 时长 | 说明 |
|------|------|------|
| 第1阶段 | 30分钟 | 首次试用，体验完整功能 |
| 第2阶段 | 5分钟 | 二次试用 |
| 第3阶段 | 5分钟 | 三次试用 |
| 第4阶段 | 5分钟 | 四次试用 |
| 第5阶段 | 5分钟 | 五次试用 |
| 第6阶段 | 5分钟 | 最后一次试用 |

- **每天0点自动重置**：所有阶段重新开始
- **阶段结束触发退出**：每个阶段时间用完后发送 `shouldDisconnect: true`

## 完整示例代码

### iOS Swift

```swift
import Foundation

class TrialManager {
    
    func handleConfigNotification(_ data: [String: Any]) {
        guard let type = data["type"] as? String, type == "TryDisconnect" else {
            return
        }
        
        let trialRequired = data["trialRequired"] as? Bool ?? false
        
        // 不需要试用限制的用户（已激活或非设备端）
        if !trialRequired {
            handleActivatedUser(data)
            return
        }
        
        // 需要试用限制的用户
        let shouldDisconnect = data["shouldDisconnect"] as? Bool ?? false
        
        if shouldDisconnect {
            handleTrialExpired(data)
        } else {
            handleTrialOngoing(data)
        }
    }
    
    // 已激活用户
    private func handleActivatedUser(_ data: [String: Any]) {
        let activated = data["activated"] as? Bool ?? false
        let level = data["activationLevelName"] as? String ?? ""
        let qualityAccess = data["qualityAccess"] as? [String] ?? []
        
        if activated {
            print("✅ 已激活用户: \(level), 可用画质: \(qualityAccess)")
        }
        // 正常处理设备状态
    }
    
    // 试用进行中
    private func handleTrialOngoing(_ data: [String: Any]) {
        let currentStage = data["currentStage"] as? Int ?? 1
        let remainingSeconds = data["remainingSeconds"] as? Int ?? 0
        
        // 可选：更新UI显示剩余时间
        updateTrialUI(stage: currentStage, remaining: remainingSeconds)
    }
    
    // 试用到期，需要退出
    private func handleTrialExpired(_ data: [String: Any]) {
        let trialEnded = data["trialEnded"] as? Bool ?? false
        let message = data["message"] as? String ?? ""
        let stageJustEnded = data["stageJustEnded"] as? Int
        let currentStage = data["currentStage"] as? Int ?? 1
        let totalStages = data["totalStages"] as? Int ?? 6
        
        // 停止推流/拉流
        stopStreaming()
        
        if trialEnded {
            // 今日全部结束
            showTrialEndedAlert(message: "今日试用次数已用完，请激活会员或明天再试")
        } else {
            // 当前阶段结束
            let remaining = totalStages - currentStage + 1
            showStageEndedAlert(
                stage: stageJustEnded ?? currentStage,
                remainingChances: remaining,
                nextStageSeconds: data["remainingSeconds"] as? Int ?? 300
            )
        }
    }
    
    private func updateTrialUI(stage: Int, remaining: Int) {
        // 更新界面显示
        let minutes = remaining / 60
        let seconds = remaining % 60
        print("⏱️ 第\(stage)阶段 剩余: \(minutes)分\(seconds)秒")
    }
    
    private func stopStreaming() {
        // 停止推流/拉流逻辑
        print("🛑 停止推流")
    }
    
    private func showTrialEndedAlert(message: String) {
        // 显示试用全部结束弹窗
        print("🚫 \(message)")
    }
    
    private func showStageEndedAlert(stage: Int, remainingChances: Int, nextStageSeconds: Int) {
        // 显示阶段结束弹窗
        let nextMinutes = nextStageSeconds / 60
        print("⏸️ 第\(stage)阶段结束，还有\(remainingChances)次机会，下次\(nextMinutes)分钟")
    }
}
```

## 核心字段速查表

| 字段 | 类型 | 说明 | 前端用途 |
|------|------|------|----------|
| `shouldDisconnect` | Boolean | **是否需要强制退出** | `true`时立即断开连接 |
| `trialRequired` | Boolean | 是否需要试用限制 | 判断用户类型 |
| `trialEnded` | Boolean | 当天试用是否全部结束 | 区分"阶段结束"和"全部结束" |
| `currentStage` | Integer | 当前/下一阶段号 | 显示阶段信息 |
| `remainingSeconds` | Integer | 剩余秒数 | 显示倒计时 |
| `stageJustEnded` | Integer | 刚结束的阶段号 | 提示用户刚结束的阶段 |
| `message` | String | 提示信息 | 直接显示给用户 |
| `activated` | Boolean | 是否已激活 | 判断是否显示激活按钮 |
| `qualityAccess` | Array | 可用画质列表 | 显示可选画质选项 |

## ⚠️ 强制退出汇总

### 登录时判断（进入主页前）

| 情况 | `trialRequired` | `trialEnded` | 处理 |
|------|-----------------|--------------|------|
| 已激活用户 | `false` | - | ✅ 直接进入主页 |
| 非设备端用户 | `false` | - | ✅ 直接进入主页 |
| 还有试用时间 | `true` | `false` | ✅ 进入主页，开始试用 |
| **当天试用已用完** | `true` | `true` | ❌ **弹框 → 点确定 → 强制退出** |

### 推流时判断（使用中）

| 情况 | `shouldDisconnect` | `trialEnded` | 处理 |
|------|-------------------|--------------|------|
| 正常使用中 | `false` | `false` | ✅ 继续使用 |
| 已激活用户 | `false` | - | ✅ 无限制 |
| **阶段时间用完** | `true` | `false` | ❌ **强制退出** |
| **全部次数用完** | `true` | `true` | ❌ **强制退出** |

## 常见问题

### Q1: 登录时发现当天试用已用完怎么办？
**A**: 弹框提示"今日试用已用完"，用户点击"确定"后强制退出应用。**不允许进入主页**。

### Q2: 阶段结束后如何开始下一阶段？
**A**: 用户需重新打开应用/重新发起连接推流。后端会自动进入下一阶段，并从0秒开始计时。

### Q3: 每个阶段是独立计时还是累计？
**A**: 独立计时。每个阶段有自己的时长（第1阶段30分钟，2-6阶段各5分钟），阶段结束后`usedSeconds`重置为0。

### Q4: 如果用户中途断开再连接，时间怎么算？
**A**: 继续之前的进度。比如第1阶段用了15分钟后断开，重连后继续从15分钟开始计时，还剩15分钟。

### Q5: 每天几点重置？
**A**: 每天0点（服务器时间）自动重置所有用户的试用阶段和时间。

### Q6: 已激活用户会收到 shouldDisconnect: true 吗？
**A**: 不会。已激活用户 `trialRequired: false`，`shouldDisconnect` 始终为 `false`。

### Q7: 登录和推流的判断有什么区别？
**A**: 
- **登录时**：检查 `trialInfo.trialEnded`，如果为 `true` 则不允许进入主页
- **推流时**：检查 `shouldDisconnect`，如果为 `true` 则强制退出
